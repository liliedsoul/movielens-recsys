# Рекомендательная система фильмов (MovieLens)

Курсовая работа: разработка рекомендательной системы фильмов методами
коллаборативной фильтрации на наборе данных MovieLens.

## Данные

- **ml-25m** — основной набор: 25 млн оценок, 162 541 пользователь, 59 047 фильмов (1995–2019).
- **ml-latest-small** — компактный набор (~100 тыс. оценок) для отладки.

Данные хранятся вне git, под управлением DVC (`data/raw/*.dvc`).

## Запуск

```bash
uv sync      # установить окружение по uv.lock
dvc pull     # получить данные из хранилища DVC
```

Параметры экспериментов — в `configs/params.yaml`.

## Структура

- `configs/` — параметры экспериментов
- `data/raw/` — исходные данные (DVC)
- `notebooks/` — разведочный анализ данных (EDA)
- `reports/` — графики и текст отчёта
- `src/` — исходный код (в разработке)
- `tests/` — тесты
