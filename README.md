# Рекомендательная система фильмов (MovieLens)

Курсовая работа: разработка рекомендательной системы фильмов методами
коллаборативной фильтрации на наборе данных MovieLens. В этом же репозитории
выполняются практические работы по дисциплине «Технологии и инструментарий
машинного обучения» (ТИМО).

## Данные

- **ml-25m** — основной набор курсовой: 25 млн оценок, 162 541 пользователь, 59 047 фильмов (1995–2019).
- **ml-latest-small** — компактный набор (~100 тыс. оценок): отладка и практические работы по ТИМО.

Исходные данные хранятся вне git, под управлением DVC (`data/raw/*.dvc`).

## Запуск

```bash
uv sync      # установить окружение по uv.lock
dvc pull     # получить данные из хранилища DVC
```

Параметры экспериментов — в `configs/params.yaml` (раздел `batches` и `model` — для практических работ ТИМО).

### Практические работы ТИМО

```bash
uv run python -m src.data.split_batches     # ПР 2: исходная часть 60 % + порции batch_01…04
uv run python -m src.data.eda_pr2           # ПР 2: разведочный анализ исходной части
uv run python -m src.models.experiments     # ПР 3: сравнение моделей (≈ 6 мин)
uv run python -m src.models.train           # ПР 3: обучение и сохранение итоговой модели
uv run python -m src.features.build data/incoming/batch_01.csv   # любой файл → признаки для модели
uv run pytest                               # тесты пайплайна
```

## Структура

- `configs/` — параметры экспериментов
- `data/raw/` — исходные данные (DVC)
- `data/base/`, `data/incoming/` — исходная часть и порции новых данных (ПР 2)
- `data/metadata/data_versions.csv` — число строк и SHA-256 каждого файла
- `src/data/` — разбиение на порции, EDA
- `src/features/` — пайплайн подготовки данных и признаков (ПР 3)
- `src/models/` — эксперименты и обучение итоговой модели (ПР 3)
- `models/` — сохранённая модель и её описание
- `notebooks/` — разведочный анализ данных (EDA) курсовой
- `reports/` — графики, таблицы экспериментов и отчёты
- `docs/diagrams/` — диаграммы C4 и UML (ПР 2)
- `tests/` — тесты
